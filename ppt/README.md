# Social Network Friend Recommendation Engine
# ⭐ Social Network Friend Recommendation Engine

A graph-based friend recommendation system built using **C++**, **Graph Data Structure**, and **Breadth First Search (BFS)** with an interactive **HTML, CSS, and JavaScript** frontend.

## Project Overview

The Social Network Friend Recommendation Engine is a graph-based application developed using C++ to simulate a social networking platform. The project demonstrates the practical implementation of Graph Data Structures and the Breadth First Search (BFS) algorithm for managing user relationships, recommending friends, and finding the shortest connection between users.

A responsive frontend developed using HTML, CSS, and JavaScript provides an interactive interface to visualize the project and demonstrate its functionalities.

---

## Objectives

- Implement Graph Data Structure using an adjacency list.
- Apply Breadth First Search (BFS) for graph traversal.
- Recommend friends based on existing network connections.
- Find the shortest path between two users.
- Demonstrate the real-world application of Data Structures and Algorithms.
